# 旺达年龄条 / Wanda Age Bar

## 中文

饥荒联机版客户端模组，在物品栏上方显示旺达的年龄条和年龄数字。左侧接近老死，右侧更年轻；不同颜色区间便于快速辨认。指针和年龄数字使用游戏同步的生命比例，与原版时钟的计算方式一致。原版时钟保留；只有使用旺达时显示，鬼魂状态下隐藏。

指针左侧以颜色填充，右侧为空槽。

将模组放在游戏的 `mods` 目录，在客户端模组菜单中启用。服务器和其他玩家无需安装。

## English

A client-only Don't Starve Together mod that displays Wanda's age and a color-banded age bar above the inventory. The left end is near death from old age; the right end is younger. The marker and age use the game's synchronized health percentage, following the original age clock's calculation. The original clock remains visible. The bar appears only when playing Wanda and is hidden while she is a ghost.

The bar is colored to the left of the marker and empty to its right.

Place the mod in the game's `mods` directory and enable it in the client mod menu. The server and other players do not need it.
