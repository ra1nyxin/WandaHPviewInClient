# 旺达年龄条 / Wanda Age Bar

作者 / Author: ra1nyxin

客户端模组，在旺达的物品栏上方显示年龄进度条。左侧接近老死，右侧更年轻，指针与年龄数字使用原版同步的生命比例。原版年龄时钟仍然保留。只有自己使用旺达时显示，鬼魂状态下隐藏。

在模组菜单中启用即可，无需服务器或其他玩家安装。

This client-only mod displays Wanda's age above the inventory. The left end is near death from old age; the right end is younger. The marker and age use the health percentage synchronized by the game. The original age clock remains visible. The bar is shown only for the local Wanda and is hidden while a ghost.

Enable it in the client mod menu. The server and other players do not need it.
